# MSSP 2024 monitoring report

Descriptive analysis of CMS Performance Year 2024 financial and quality results for 476 ACOs.

| Measure | Result |
| --- | ---: |
| ACOs | 476 |
| Spending below benchmark | 422 |
| Spending above benchmark | 54 |
| Net benchmark minus expenditures | $6.61 billion |
| Net earned savings minus owed losses | $4.12 billion |
| Positive / zero / negative earned or owed amounts | 360 / 100 / 16 |

The benchmark difference is **not** the payment earned by an ACO. The figures are descriptive and not causal estimates. Risk model denotes one-sided or two-sided financial risk, not clinical risk adjustment. Quality scores are CMS-reported.

This report reflects the summary results already documented in the project README. Running `medicare-apm-advanced.py` regenerates this report with full-precision amounts from the source CSV. See the accompanying output tables and figures for detailed comparisons.
